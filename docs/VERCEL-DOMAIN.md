# חיבור הדומיין ב-Vercel

## קודם כול: לוודא שזו באמת הבעיה

לפתוח בדפדפן `https://megalim-israel.co.il`.

- **נטענת האפליקציה** → הדומיין מחובר, והבעיה במקום אחר
- **שגיאת DNS / "לא ניתן להגיע לאתר"** → הדומיין לא מצביע ל-Vercel. זה המדריך הזה
- **דף של Vercel עם 404 או "Domain not configured"** → ה-DNS מגיע, אבל הדומיין לא
  משויך לפרויקט הנכון

---

## חילוץ מיידי: להחזיר את ההתחברות לעבוד עכשיו

אם עדכנת את **Site URL** ב-Supabase לדומיין החדש לפני שהוא חי, ההתחברות עם
Google ו-Facebook נשברה — Supabase מסיים את סבב ה-OAuth בהפניה לכתובת מתה.

**Supabase** ← Authentication ← URL Configuration ← **Site URL** בחזרה ל:

```
https://magalim-israel.vercel.app
```

ההתחברות חוזרת לעבוד תוך שניות. להחזיר לדומיין החדש רק אחרי שהוא טוען.

> קישורי הזמנה ממשיכים לעבוד בשני המצבים — הם לא עוברים דרך Site URL.

---

## 1. להוסיף את הדומיין לפרויקט

**Vercel** ← הפרויקט ← **Settings** ← **Domains** ← **Add**

להוסיף **את שניהם**:

```
megalim-israel.co.il
www.megalim-israel.co.il
```

Vercel יציע להפוך אחד לראשי ואת השני להפניה. **לבחור את הגרסה בלי `www` כראשית** —
זו הכתובת שכבר כתובה בכל מקום בקוד (`SITE_HOST`, `twa-manifest.json`), ושינוי שלה
דורש עוד סבב.

---

## 2. ה-DNS — שתי דרכים

**"Invalid Configuration" פירושו שהדומיין נוסף לפרויקט, אבל Vercel לא מוצא את
רשומות ה-DNS שהוא מצפה להן.** כלומר הצד של Vercel כבר בסדר; מה שחסר הוא אצל הרשם.

### דרך א׳ — להעביר את ה-DNS ל-Vercel (הפשוטה)

במסך Domains, לשונית **Vercel DNS**. Vercel ייתן שני Nameservers
(‎`ns1.vercel-dns.com` וכדומה), ומשנים אליהם אצל הרשם.

מרגע זה Vercel מנהל את כל ה-DNS של הדומיין לבד, ואין רשומות להגדיר ידנית. שינוי
Nameservers לוקח בדרך כלל יותר זמן להתפשט מרשומה בודדת, אבל אין בו מה לטעות.

> **מתי לא:** אם יש או יתכן שיהיה דוא"ל על הדומיין. העברת Nameservers מעבירה גם
> את רשומות ה-MX, וצריך ליצור אותן מחדש ב-Vercel. לדומיין חדש בלי דוא"ל — לא רלוונטי.

**מלכודת במסך ה-Name Servers של חלק מהרשמים (בהם Box):** לצד שדה ה-Host-Name יש
שדות `Host Address (IPv4)` ו-`(IPv6)`. הם נראים כאילו צריך למלא אותם, ולעיתים אף
מציגים `127.0.0.1` באפור — **זה placeholder, לא ערך**.

השדות האלה הם *glue records*, ונחוצים רק כששרת השמות עצמו נמצא בתוך אותו דומיין.
שרתי השמות של Vercel חיצוניים, ולכן **יש להשאיר את שני שדות הכתובת ריקים לגמרי**.
מילוי שלהם ישבור את ההפניה.

צריך גם **למחוק שורות ישנות שנשארו**. אם היו שלושה שרתים של הרשם ו-Vercel נותן שניים,
השורה השלישית חייבת להתרוקן — אחרת חלק מהשאילתות ימשיכו להגיע לרשם הישן והתוצאה
תהיה לא עקבית.

### דרך ב׳ — רשומות ידניות אצל הרשם

Vercel מציג **בדיוק** אילו רשומות להגדיר. **להשתמש במה שמוצג שם ולא בערכים ממדריכים,
כולל המדריך הזה** — Vercel מרחיב את טווח ה-IP שלו והערכים החדשים שונים מהישנים.

שים לב שצריך להגדיר **שתי רשומות, אחת לכל שורה** במסך:

- לשורת `www.megalim-israel.co.il` — הרשומה שמופיעה תחת **View DNS configuration** שלה
- לשורת `megalim-israel.co.il` (בלי www) — **רשומה נפרדת**, שמופיעה תחת
  **View DNS configuration** שלה. זו נשכחת בקלות, כי המסך מראה כברירת מחדל רק אחת.

הערך בעמודת Value ארוך ונחתך בתצוגת הטלפון — יש כפתור העתקה לידו. עדיף להעתיק ולא
להקליד.

**איפה מגדירים:** באזור ניהול ה-DNS אצל רשם ה-`.co.il`, אלא אם ה-Nameservers כבר
מופנים לספק אחר — ואז שם.

**לא למחוק** רשומות MX קיימות אם יש דוא"ל על הדומיין.

## 3. להמתין, ולבדוק

Vercel מאמת את ה-DNS לבד ומנפיק תעודת SSL אוטומטית. בדרך כלל דקות; אצל חלק
מרשמי `.co.il` זה יכול לקחת שעות.

במסך Domains של Vercel תופיע **✓ Valid Configuration** כשזה מוכן.

בדיקה מלאה:

```
Actions ← בדיקות ← Run workflow
```

או ידנית — `https://megalim-israel.co.il/.well-known/assetlinks.json` צריך להחזיר JSON.

---

## 4. רק אחרי שהדומיין טוען

1. **Supabase** ← Site URL בחזרה ל-`https://megalim-israel.co.il`
2. Redirect URLs — לוודא ששתי הכתובות שם, **הישנה והחדשה**
3. לבדוק התחברות עם Google ועם Facebook
4. ואז להמשיך ל-TWA (`docs/ANDROID-TWA.md`) — `assetlinks` נקרא מהדומיין, ולכן
   הוא חייב להיות חי לפני שמפרסמים

## אם משהו נתקע

**"Invalid Configuration" ב-Vercel** — שלוש סיבות, לפי שכיחות:

1. הרשומה עדיין לא הוגדרה אצל הרשם בכלל
2. הוגדרה רק לאחת משתי השורות (עם `www` ובלי) — לכל אחת רשומה משלה
3. הוגדרה, אבל עוד לא התפשטה, או שרשומה ישנה על אותו שם מתנגשת

לבדוק מבחוץ מה ה-DNS באמת מחזיר:

```bash
dig megalim-israel.co.il
dig www.megalim-israel.co.il
```

אם התשובה ריקה או מצביעה למקום אחר — הרשומה לא שם, ואין טעם ללחוץ Refresh ב-Vercel.

**הדומיין משויך לפרויקט אחר** — Vercel יסרב להוסיף אותו פעמיים. להסיר מהפרויקט הישן.

**האתר טוען אבל האפליקציה ריקה** — זו כבר לא בעיית דומיין. לפתוח את הקונסול בדפדפן;
סביר שזו שגיאת CSP או טעינת משאב.
