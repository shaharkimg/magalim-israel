# ביס־סייפ — אתר

אתר סטטי (HTML/CSS/JS, בלי build) לביס־סייפ עם לירון מעודה־כהן, קלינאית תקשורת.

## הרצה מקומית

```bash
cd bis-safe
python3 -m http.server 8000   # או: npx serve .
```
ואז לפתוח http://localhost:8000

## מבנה

- `index.html` — הכותרת, התפריט, התחתית והמסגרת.
- `styles.css` — כל העיצוב (צבעים מוגדרים כמשתנים בראש הקובץ).
- `app.js` — ניתוב בין העמודים (`#/age`, `#/consult` וכו') וכל התוכן.
- `favicon.svg` — הסמל.

## מה צריך להשלים לפני עלייה לאוויר

1. **שליחת הטופס** — ב־`app.js`, בראש הקובץ, למלא `CONFIG.formEndpoint`
   (למשל כתובת Formspree). כל עוד השדה ריק, הטופס מציג הודעת הצלחה **בלי לשלוח בפועל**.
2. **וואטסאפ** — למלא `CONFIG.whatsappNumber` בפורמט `9725XXXXXXXX`.
3. **תוכן עמודי הגיל** — המקומות המסומנים „תוכן בהכנה” הם מקומות לתוכן המקצועי
   (מה אפשר לפגוש, איך זה נראה ביום־יום, מונח, רעיון לזמן משותף, מקורות, מתי להתייעץ).
4. **ספריית ההדרכות** — הפריטים במערך `LIBRARY` הם דוגמאות למבנה ומסומנים „דוגמה”.
5. **עליי** — תמונה, והכשרה וניסיון לפי פרטים מאומתים.
6. **פרטי מנוי**, מדיניות פרטיות, תנאי שימוש והצהרת נגישות.
7. **האזור האישי** — כרגע שומר העדפות (תוכן שמור, קבוצת גיל) בדפדפן בלבד; אין עדיין התחברות משתמשים.
